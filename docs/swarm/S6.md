# Mana@Home S6: reach, cosmetics credit bridge, live watch, and WASM/Android worker

S6 of [the design](Design.md): spending matured Mana@Home credits on Playmat cosmetic capsule tokens, the public
`/swarm/watch` live game inspector, and the `wasm32` / `aarch64-linux-android` strict worker crate. S5's record is in
[S5.md](S5.md).

## What S6 built

- **Swarm credits to Playmat cosmetics bridge** (`playmat-swarm/src/bridge.rs`, `Mage.Server/.../CareerCapsules.java`,
  `CareerProgressApi.java`, `Mage.Web.Client/src/app/career/capsules/`):
  - Coordinator tracks redemptions in `credit_redemptions` while leaving lifetime leaderboard credits intact.
  - `GET /api/v1/credits/balance` (worker bearer auth) promotes matured credits past their 7-day window and reports
    pending, matured, redeemed, conversion rate (`MANA_CREDIT_PER_TOKEN`, default `100.0` credit = 1 capsule token),
    and redeemable capsule tokens.
  - `POST /api/v1/bridge/redeem` (authenticated by shared `X-Swarm-Bridge-Secret: $SWARM_BRIDGE_SECRET`) atomically
    converts a contributor's matured credit into Playmat capsule tokens and prevents double spending.
  - `Mage.Server` exposes `careerRedeemSwarmCredits(workerToken)` via `CareerCapsules.redeemSwarmCredits`, calling the
    coordinator bridge and crediting `capsule_tokens` inside a `CareerStore` transaction.
  - Playmat's Capsule Shop (`CapsuleShopScreen.tsx`) adds a `Mana@Home` claim control in the token wallet.
- **Live Watch (`/swarm/watch`)** (`playmat-swarm/src/public.rs`, `store.rs`, `SwarmScreen.tsx`):
  - `GET /api/v1/watch` lists recent games across self-play, SPRT gates, and Archbench runs.
  - `GET /api/v1/watch/{unit}/{deal}` fetches the game's answer log from the store (local or R2) and returns its
    decision tokens for step-by-step replay inspection in `/swarm/watch`.
- **Browser (WASM) and Android strict worker** (`playmat-ai/src/search.rs`, `rust/crates/playmat-worker-wasm/`):
  - Replaced bare `std::time::Instant::now()` calls in `playmat-ai/src/search.rs` with a `wasm32`-safe `Timer` shim
    so `playmat-ai --features strict` runs games on `wasm32-unknown-unknown` without trapping.
  - Added `playmat-worker-wasm` (`cdylib` + `rlib`, default `strict` feature) exposing `play_deal`, `replay_deal`,
    `determinism_class` (`strict-1`), and zero-glue `extern "C"` WASM exports (`wasm_alloc`, `wasm_free`,
    `wasm_play_deal_json`, `wasm_replay_deal_json`).
  - Verified clean compilation on both `wasm32-unknown-unknown --features strict` and
    `aarch64-linux-android --features strict`, plus native play+replay round-trip tests.
