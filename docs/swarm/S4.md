# Mana@Home S4: swarm gates and Archbench ratings

S4 of [the design](Design.md): distributed SPRT promotion gates (`UnitKind::Match`), anchored Archbench strength
ratings (`UnitKind::Bench`), automatic network promotion with a single-account concentration guard, admin hold/resume/
manual-promote/rollback controls, and the public `/swarm/networks` lineage and Elo chart view. S3's record is in
[S3.md](S3.md).

## What S4 built

- **Coordinator SPRT gates, network lineage, and Archbench ratings** (`playmat-swarm/src/gates.rs`, `src/lib.rs`,
  `playmat-swarm-proto/src/api.rs`):
  - SQLite tables `networks`, `gates`, and `benches` created idempotently in `SCHEMA`.
  - Logistic Elo, 95% confidence interval, and Fishtest trinomial SPRT log-likelihood ratio (`sprt_llr`) with
    standard Wald bounds (`ln(beta / (1 - alpha))`, `ln((1 - beta) / alpha)`).
  - `POST /api/v1/gates` (trainer/admin): publishes a `UnitKind::Match` gate round (only leased to `reputable` and
    `trusted` workers), registers the baseline and candidate networks, and tracks SPRT progress.
  - Automatic gate evaluation on every unit acceptance (`verify_complete` and `verdict`):
    - **Early stop on pass/fail**: when LLR crosses the upper or lower bound, remaining queued match units in the gate
      round are automatically cancelled.
    - **Single-account concentration guard**: if SPRT passes (`llr >= upper_bound`) while one account contributed more
      than `max_share` (default 50%) of un-reverified games, the gate pauses in `concentration-hold` and automatically
      queues cross-account `VerifyMode::Rerun` units until the share drops below `max_share`.
    - **Automatic promotion**: once SPRT passes, concentration is satisfied, `auto_promote` is true, and the gate is
      not held by staff, the candidate network is promoted automatically, prior promoted networks move to `superseded`,
      and a `gate-pass` entry is written to the public transparency audit log.
  - Admin controls (`POST /api/v1/admin/gates/{id}/hold`, `resume`, `promote`, and `POST /api/v1/admin/networks/rollback`):
    - Promoting a gate that has not passed SPRT, or rolling back the active network to a previous SHA-256, requires a
      written reason that is recorded in the public transparency audit log.
  - Archbench rating runs (`POST /api/v1/bench`, `GET /api/v1/benches`, `GET /api/v1/networks`):
    - Runs `UnitKind::Bench` units against fixed non-evolving anchor opponents (default anchor `host@s6 = 1000` Elo),
      computing overall anchored Elo, 95% CI, and per-anchor W/D/L scores stored on `networks`.
    - Registered networks are downloadable publicly via `GET /api/v1/nets/{sha}` without a bearer token.
- **Worker and trainer CLI** (`playmat-worker/src/main.rs`, `rust/rl/swarm.py`):
  - `playmat-worker` executes `UnitKind::Bench` units alongside `UnitKind::Match` (non-recording, full answer logs and
    strict bit-for-bit verification).
  - `swarm.py` adds `networks`, `gates`, `benches`, `publish-gate`, `publish-bench`, `hold-gate`, `resume-gate`,
    `promote-gate`, and `rollback`.
- **Public tracker and admin UI** (`Mage.Web.Client/src/app/swarm/`, `src/app/admin/SwarmPage.tsx`):
  - Public `/swarm/networks` tab: Archbench Elo-over-generations SVG chart (anchored to `host@s6 = 1000`, with a note
    distinguishing Archbench ratings from self-play Elo), SPRT gate LLR progress bars with concentration share readout,
    and network lineage table with per-anchor scores and `.pmnet` downloads.
  - Admin `/admin#swarm` `Gates & Networks` tab: Hold, Resume, Promote (written reason required when unpassed), and
    Rollback (written reason required).

## S4 gate: a swarm gate agrees with a trusted-only gate

Verified end to end with the real strict engine and worker (`cargo test -p playmat-worker --features strict s4_`):

- `s4_gate_swarm_agrees_with_trusted_only_gate` runs the same `UnitKind::Match` deals through two independent
  coordinators:
  1. A trusted-only gate run solely on a `trusted` worker.
  2. A mixed swarm gate with `reputable` workers, a planted sandbagger that flips game winners on unit 0, and a
     `trusted` verifier. The verifier catches the sandbagger bit-for-bit, unit 0 is reissued to honest `reputable`
     workers, and verified results are accepted.
  - Both coordinators finish with identical `wins`, `draws`, `losses`, `elo`, `llr`, and `status`.
- `s4_bench_unit_runs_through_real_worker_and_rates_network` runs a `UnitKind::Bench` unit against `host@s6` through a
  reputable worker and trusted re-run verifier and asserts the network receives its anchored Elo and per-anchor score
  on `GET /api/v1/networks`.
- Integration tests in `playmat-swarm/tests/s4_gates.rs` verify SPRT early stopping, the single-account concentration
  guard spawning cross-account re-runs before auto-promotion, admin hold/resume/manual-promote/rollback validation,
  public audit logging, and Archbench ratings.
