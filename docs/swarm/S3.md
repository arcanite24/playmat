# Mana@Home S3: public tracker, teams, and admin console

S3 of [the design](Design.md): the public `/swarm` tracker, time-windowed contributor and team leaderboards,
contributor profiles and badges, the public transparency log, live SSE updates, and the staff `Swarm` admin console.
S2's record is in [S2.md](S2.md).

## What S3 built

- **Coordinator public tracker API and teams** (`playmat-swarm/src/public.rs`, `src/lib.rs`):
  - CORS middleware on `/api/v1/*` so `playmat.deimos.studio/swarm` (and local dev servers) can read the public
    coordinator directly.
  - Live SSE endpoint `GET /api/v1/events` emitting `status` snapshots every 5 seconds.
  - Enriched `GET /api/v1/status` with `total_decisions`, `platforms` (10-minute active host OS mix), and
    `active_round`.
  - Public read-only routes:
    - `GET /api/v1/projects`: all rounds with progress, priority, trained flag, unit counts, and pending verify count.
    - `GET /api/v1/feed`: recently accepted units.
    - `GET /api/v1/leaderboard?window=24h|7d|30d|all`: time-windowed contributor leaderboard with team name.
    - `GET /api/v1/teams?window=24h|7d|30d|all` plus `POST /api/v1/teams`, `POST /api/v1/teams/{id}/join`, and
      `POST /api/v1/teams/leave` (team credit counts members' accepted work from the timestamp they joined).
    - `GET /api/v1/contributors/{name}`: trust tier, team, badges, credit breakdown, hosts, and recent accepted units.
    - `GET /api/v1/transparency`: aggregate accepted/verified/rejected/quarantined counts and the public subset of run
      and verification audit events (excluding private staff moderation notes).
  - Idempotent SQLite migrations add `teams`, `tokens.team_id`, and `tokens.team_joined_at` in place.
- **Public `/swarm` tracker** (`Mage.Web.Client/src/app/swarm/`):
  - Mounted outside `<SignedIn>` in `src/app/main.tsx` at `/swarm`, `/swarm/:section`, and
    `/swarm/contributors/:name`.
  - Views: Overview (SSE live KPIs, active round progress bar, platform mix, accepted feed), Projects, Leaderboards
    (Contributors and Teams with `24h`/`7d`/`30d`/`all` windows), Contributor Profile, Transparency, and Contribute
    (copyable Docker and native strict CLI setup commands).
- **Admin `Swarm` console** (`Mage.Web.Client/src/app/admin/SwarmPage.tsx`):
  - Added as the `Swarm` tab in `/admin` (`role: 'admin'`), authenticating directly against the coordinator with an
    admin bearer token stored only in `sessionStorage`.
  - Sections: Verification Inbox (`confirm-cheat`, `false-positive`, `order-rerun`, `dismiss`), Rounds & Queue
    (reprioritize, cancel queued/all, mark trained, order re-run, reissue unit), Workers & Tokens (mint token, set
    trust tier, quarantine/restore, credit adjustment with written reason, revoke), and filterable Audit Log.
