Progress report

Moving the server to Rust.

Playmat runs on XMage, a Java rules engine. A game against the AI with real decks costs the server 8 to 12 seconds of CPU, almost all of it the AI thinking. We're rewriting the engine and the AI in Rust a piece at a time, with Java still there behind each piece, until AI games cost a fraction of that. Since 11 Nov a game against the AI can run on the Rust engine from start to finish: turn on Play on the Rust engine in Settings.

Counted from the repository on every change.

        What an AI game costs the server

        Cards

        A game runs on Rust only when every card in both decks is in the Rust engine. A transpiler turns XMage's Java card files into data; the rest is written by hand. The first target is the Pioneer and Standard decks the AI plays.

        The 24 meta decks, one by one

          Does it play the same as Java?

          Every change is checked with shadow games: Java plays a seeded game and records every choice and the full game state after each step; the Rust engine replays the same choices and must reach the same state at every step. Cards come in by tiers of decks. A tier goes in once its games match; some of them are kept in the repository and replayed on every change.

            What the port found in Java

            Comparing every step of a Java game with a Rust replay turns up XMage's own problems as well as Rust's. This is everything found so far (15 Nov). Where Java breaks the rules, Rust follows the rules and the game counts as a Java bug. Where Java's order is random, the card stays unverified, since no replay can match it. None of these have been fixed in Java yet. The details are in the engine notes.

            Rules bugs Rust doesn't copy

            • Fatehold Charm can target itself (rule 115.5). Its "return target spell" mode picks the charm while it's on the stack. Two of the 10,000 gate games.
            • Back faces with mana value 0 (rule 712.8e). A permanent put onto the battlefield transformed keeps transformed=false in PermanentCard when its front is a sorcery (Esper Origins), and PermanentToken.getManaValue does the same for a copy token's back face. Three gate games.
            • The Fall of Kroog can't be cast from the hand. Its target class reads the first target off the stack object, which doesn't exist yet.
            • Elemental Expressionist never triggers, and Java then asks which replacement goes first.
            • Blightbeetle: a creature entering under an opponent's control still gets its +1/+1 counter.
            • Tribute to Horobi: Echo of Death's Wail can sacrifice itself as "another creature", because the transformed face's abilities have a different source than the permanent.
            • "Target player shuffles target cards from their graveyard" lets you pick any graveyard card. The target class overrides only a canTarget that neither choosing nor resolving calls.
            • "If you cast it from your hand" (CastFromHandSourcePermanentCondition) is false in games where it should be true. Its watcher compares steps by object identity.
            • Zhur-Taa Druid doesn't trigger when it's tapped while paying for a spell, because of another identity check.
            • Last known information lasts too long: a creature sacrificed earlier in the same priority can still trigger (Agent Venom).
            • Two abilities of one object on the stack share an id, so a target on the stack is ambiguous (Agonasaur Rex, Defabricate).

            Java quirks Rust copies, to match

            • A modal trigger can counter itself. Its "counter target activated or triggered ability" mode can be chosen when the trigger is the only target (Subcommander T'Pol).
            • Lost "otherwise" texts. DoIfCostPaid's copy constructor drops setOtherwiseText, so Rent Is Due shows "If you don't".
            • Ignored settings. Java never reads setCanWorksOnStackOnly on SpellCostReductionForEachSourceEffect (Huskburster Swarm).

            Java's AI

            • It spends restricted mana where it shouldn't. Chandra's Embercat's mana pays for a spell that isn't an Elemental (Fluxcharger).
            • It taps sources that make nothing while paying (Nyx Lotus, Zariel, Three Tree City, Astral Cornucopia, Vivi Ornitier).
            • It drops a trigger when the only target is its own creature (Ruthless Sniper).

            Random order from hash sets and maps

            Java walks a HashSet or HashMap keyed by random ids or identity hashes, so the same seeded game can play out differently from run to run.

            • Cards reaching the hand: Accumulate Wisdom (Target.java's Collectors.toSet(), one gate game), Pearl Lake Ancient, Volt Charge, Smuggler's Surprise, Greenhouse // Rickety Gazebo, The Three Seasons, Ulamog's Despoiler and Blight Herder. LinkedHashSet would fix most of these.
            • The order in the graveyard: sacrifices (Pitiless Carnage, Winnowing) and returns (Mnemonic Betrayal).
            • Tokens created together (withAdditionalTokens: Forbidden Friendship, Reckoner Bankbuster) and tokens for each player (Soul of Emancipation).
            • Shuffling each owner's library (Turn the Earth), attack triggers in getAttackers() order (Eternal of Harsh Truths, Wildfire Eternal), and which permission a cast uses (Garruk's Horde beside Bolas's Citadel).
            • Random discards picked from a HashSet (Rowdy Crew, Curse-Marred Demon), so they can't be ported as written.

            Crashes, hangs and tooling

            • Unfinished games. Of the 10,000 gate games, Java timed out in 44 and threw a RejectedExecutionException in 1.
            • Exceptions mid-game, rolled back: Vesuvan Drifter copying a double-faced card, and Emergent Sequence finding nothing.
            • The text deck importer reads the "/" in Summon: Choco/Mog as a split card, so no deck file can hold it.
            • Games that end strangely: one player lost with every zone empty after the AI switches back and forth (Raubahn, Wandering Fumarole).

            Not understood yet

            • Yorion can choose itself when it returns, though its filter (AnotherPredicate) says it can't.
            • Vicious Verse: when a stolen Hallway Heckler prepared it, Java won't let it be cast from exile (Bombur's game).
            • Discover the Impossible: the spell still resolving can be targeted by a counterspell cast from it.
