Progress report

Moving the server to Rust.

Playmat runs on XMage, a Java rules engine. A game against the AI with real decks costs the server 8 to 12 seconds of CPU, almost all of it the AI thinking. We're rewriting the engine and the AI in Rust a piece at a time, with Java still there behind each piece, until AI games cost a fraction of that.

Counted from the repository on every change.

Headline numbers

    Where it stands

    Two tracks. The server one moves everything around the game to Rust, each piece answered by Java and Rust side by side until they agree. The game one puts AI games themselves on the Rust engine.

        What an AI game costs the server

        Cards

        A game runs on Rust only when every card in both decks is in the Rust engine. A transpiler turns XMage's Java card files into data; the rest is written by hand. The first target is the Pioneer and Standard decks the AI plays.

        The 24 meta decks, one by one

          Does it play the same as Java?

          Every change is checked with shadow games: Java plays a seeded game and records every choice and the full game state after each step; the Rust engine replays the same choices and must reach the same state at every step. Cards come in by tiers of decks. A tier goes in once its games match; some of them are kept in the repository and replayed on every change.
