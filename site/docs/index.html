Docs

The technical side of Playmat: running a server for your group, keeping it up to date, and the admin tools. For playing, you don't need any of this: open playmat.deimos.studio or download the app.

  • Run a server

    Start your own Playmat server with Docker, on a home machine or a VPS with a domain.

  • Updating

    Get new versions: the admin console says when one is out, and the Update button installs it.

  • Staff and the admin console

    Roles, the console sign-in, maintenance and the audit log.

  • Single sign-on

    Sign players in through Authelia, Authentik, oauth2-proxy or Tailscale.

  • Capsule machines

    Career's gachapon: tokens, the numbers to tune, and adding a machine.

Every setting, LAN servers without a domain, running behind another reverse proxy, backups and capacity numbers are in the deployment guide in the repository. These pages are the short version, and they grow as features do.

Something wrong or missing here? The docs are in the repository; open an issue or a pull request.
